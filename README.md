# Grupo de Estudos Database

Projeto acadêmico desenvolvido individualmente durante os estudos de Banco de Dados, utilizando MySQL/MariaDB.

## Sobre o projeto

O projeto consiste na criação de um banco de dados para gerenciamento de alunos e grupos de estudo.

A estrutura permite relacionar cada aluno a um grupo de estudos e armazenar informações como nome do grupo e área de estudo.

## Estrutura do banco

O banco possui duas tabelas principais:

* **aluno** — armazena os alunos cadastrados.
* **grupo** — armazena os grupos de estudo e suas respectivas áreas.

As tabelas possuem um relacionamento por meio da chave estrangeira `id_grupo`.

##  Tecnologias

* MySQL
* MariaDB
* SQL

## Conceitos praticados

* Criação de bancos de dados
* Criação de tabelas
* Chaves primárias (`PRIMARY KEY`)
* Chaves estrangeiras (`FOREIGN KEY`)
* Relacionamentos entre tabelas
* `AUTO_INCREMENT`
* `INSERT`
* Definição de tipos de dados
* Modelagem de banco de dados relacional

## Objetivo

Praticar os fundamentos de SQL e compreender a estrutura e os relacionamentos de um banco de dados relacional.

## Contexto

Projeto desenvolvido individualmente como atividade acadêmica durante a formação em Análise e Desenvolvimento de Sistemas.
